# Green Screen

Green Screen is a Minecraft 1.21.1 mod built with NeoForge.

## Development

Requirements:

- JDK 21
- IntelliJ IDEA or another Gradle-aware Java IDE

Common commands:

```powershell
.\gradlew.bat runClient
.\gradlew.bat runServer
.\gradlew.bat build
```

The built mod jar is written to `build/libs/`.

## Version Stack

- Minecraft: 1.21.1
- NeoForge: 21.1.228
- ModDevGradle: 2.0.141
- Parchment: 2024.11.17 for Minecraft 1.21.1
- Gradle wrapper: 9.2.1
